# Skills

These folders are complete, unchanged copies from [Jakubantalik/transitions.dev](https://github.com/Jakubantalik/transitions.dev/tree/e2d5551656e4d3274e075d1cbd9a95af50f53225/skills).

- `transitions-dev/`: CSS transition recipes, reference documents, and motion tokens.
- `transitions-polish/`: motion refinement guidance, supporting rules, and motion tokens.

## Download on your work computer

Clone the branch containing these skills:

```sh
git clone --branch agent/add-article-quality-framework https://github.com/tommyc10/working-notes-lab.git
```

Alternatively, download this branch as a ZIP from GitHub and extract it. Both complete skill folders are inside `skills/`.

Copy the complete folders into the skills directory supported by your coding agent. Keep the supporting files alongside each `SKILL.md`; keep both skill folders as siblings so their cross-references work. Downloading the repository alone does not install the skills into your agent.
